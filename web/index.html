01

Ce que fait le traitement

Correspondances sûres

Les libellés exacts ou les seules variations typographiques validées sont indexés.

Texte préservé

La graphie originale reste inchangée dans le XML source, même lorsqu’une variante est reconnue dans le thesaurus.

Exceptions documentées

Les concepts absents ou ambigus ne sont pas corrigés automatiquement.
